Kalender Bali API

High-performance REST API untuk Libur Nasional & Kalender Bali (ElysiaJS & Bun)

Vercel Ready Rate Limit: 120 req/min v1.0.50

Tentang API & Penggunaan Dasar

Kalender Bali API adalah layanan backend modular berbasis TypeScript yang menghitung penanggalan tradisional Bali (Wewaran, Pawukon, Sasih, Rahinan, Otonan, Odalan, Dewasa Ayu, Upacara Besar) serta Hari Libur Nasional Indonesia secara akurat.

Base URL /api/...
Format Tanggal YYYY-MM-DD (e.g. 2026-03-19)
Rate Limit Headers x-ratelimit-*

1. Kalender Bulanan

GET /api/calendar

Mengambil data kalender komprehensif (libur nasional & rahinan bali) untuk satu bulan penuh.

Query Parameters

  • year (number): Tahun Masehi (contoh: 2026)
  • month (number): Bulan 1-12 (contoh: 3)

Contoh Request (cURL)

curl -i "https://your-domain.vercel.app/api/calendar?year=2026&month=3"

2. Rahinan Bali

GET /api/rahinan

Mengecek rahinan (Purnama, Tilem, Kajeng Kliwon, Tumpek, Buda Keliwon, dll) pada tanggal tertentu atau rentang tanggal.

Cek Per Tanggal GET /api/rahinan?date=2026-03-19 Parameter: date (YYYY-MM-DD)
Cek Rentang Tanggal GET /api/rahinan/range?start=2026-03-01&end=2026-03-31 Parameter: start, end

3. Libur Nasional & Cuti Bersama

GET /api/libur-nasional

Informasi hari libur nasional Indonesia, cuti bersama, pengecekan tanggal merah, dan perhitungan hari kerja (workdays).

/api/libur-nasional ?year=2026 (Daftar libur setahun)
/api/libur-nasional/check ?date=2026-03-19 (Cek libur)
/api/libur-nasional/next ?from=2026-03-01 (Libur terdekat)
/api/libur-nasional/workdays ?start=...&end=... (Hitung hari kerja)

4. Otonan (Weton 210 Hari)

GET /api/otonan

Menghitung jadwal otonan berdasarkan hari lahir Masehi (siklus 210 hari Pawukon).

/api/otonan ?birth=2004-07-05&count=6
/api/otonan/next ?birth=2004-07-05 (Otonan terdekat)
/api/otonan/check ?birth=...&date=... (Cek hari otonan)
/api/otonan/year ?birth=...&year=2026 (Otonan tahun ini)

5. Dewasa Ayu (Hari Baik)

GET /api/dewasa-ayu

Pencarian hari baik (dewasa ayu) untuk berbagai keperluan upacara, pernikahan, ngaben, membangun rumah, dll.

/api/dewasa-ayu ?date=2026-03-19&konteks=umum
/api/dewasa-ayu/best ?start=...&end=...&konteks=pernikahan&topN=5
/api/dewasa-ayu/next ?from=...&days=30&konteks=ngaben

6. Odalan & Upacara Besar

GET /api/odalan

Jadwal odalan pura (berdasarkan wuku atau sasih) serta ringkasan karya agung dan upacara besar Hindu Bali.

/api/odalan/presets Daftar preset pura terkenal
/api/odalan ?id=pura_besakih_purnama_kadasa
/api/upacara-besar/ringkasan ?from=2026-01-01
/api/meta Metadata lengkap daftar endpoint
